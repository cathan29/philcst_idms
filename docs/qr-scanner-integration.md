# QR scanner integration

Initial support targets USB 2D scanners in keyboard/HID mode. The browser maintains focus on a text field and submits on a configured terminator. The UI may state “ready for input” but must not claim the scanner is connected without a heartbeat-capable integration.

The resolver accepts controlled opaque UUID tokens and conservative student-number payloads. Institutional URL and legacy formats remain disabled until representative authorized samples are supplied. Never navigate to a scanned URL or execute payload content. Store a keyed fingerprint rather than raw sensitive payloads when diagnostics are needed.
